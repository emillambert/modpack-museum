# Classic Warfare

Planned collection inspired by the Voltz era.

Target experiences:

- industrial electricity
- reactor systems
- radiation and protective equipment
- missiles and launch systems
- radar / detection
- forcefields
- defensive infrastructure
- team warfare
- destructive systems designed with server safeguards and seasonal PvP worlds in mind

The PvE mode should make the engineering systems usable without requiring warfare; PvP should embrace the arms-race character of the historical pack style.
