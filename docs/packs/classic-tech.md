# Classic Tech

Classic Tech is the first Modpack Museum collection. It targets the gameplay feel of the Tekkit Classic era without distributing the original pack or its binaries.

## Pillars

- industrial progression
- ore processing
- generators and storage
- visible power networks
- quarries and automated mining
- pipes/tubes and routing
- transmutation / EMC-style progression
- powered tools
- nuclear-reactor-style late game
- logic/automation

## Vertical slice

The first playable loop should be:

```text
mine copper/tin/iron
      ↓
build generator
      ↓
build cable + storage
      ↓
build macerator
      ↓
2x ore processing
      ↓
build powered furnace
      ↓
build quarry + pipes
      ↓
unlock EMC/transmutation
```

## Fidelity targets

Where historical mechanics are recreated, document the exact era and source. Balance should initially favor recognizability over modernization, followed by measured fixes for exploits/performance that are incompatible with a persistent public server.
