# Vision

Modpack Museum is a playable preservation project, not an emulator and not a binary compatibility layer.

The intended player experience is simple: use current Minecraft Java, join one address, enter **The Archive**, choose a classic collection, and play. The server handles translation, content, and the resource pack.

The preservation target is the *experience* that made the old packs memorable: recognizable progression loops, machines, automation, danger, exploration, overpowered discoveries, strange interactions, and multiplayer stories.

Fidelity is important, but blind duplication is not. Modern security, performance, accessibility, exploit resistance, and server stability may justify carefully documented differences.

## Collections

**Classic Tech** preserves the early industrial sandbox: ore doubling, power networks, quarries, pipes, transmutation, powered tools, reactors, logic and automation.

**Classic Adventure** preserves the adventure-pack style: dense structures, battle towers, bosses, wild loot, unusual equipment, large dungeons and dimension-like exploration.

**Classic Warfare** preserves the multiplayer technology arms race: generators, factories, reactors, radiation, radar, missiles, defenses and forcefields.

## What this is not

- not an official continuation of any historic modpack
- not a rehost of old mod binaries
- not a launcher
- not a requirement for players to install client mods
- not a generic minigame network
- not a pay-to-win public server
