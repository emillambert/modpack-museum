# Brand

## Name

**Modpack Museum**

## Tagline

**Classic modpacks. Modern Minecraft. No launcher.**

## Lobby

**The Archive**

The lobby is framed as a museum/archive of playable eras rather than a conventional minigame hub.

## Collection names

- **Classic Tech** — early industrial/automation era
- **Classic Adventure** — Hexxit-style adventure era
- **Classic Warfare** — Voltz-style engineering/warfare era

These names are intentionally project-owned and descriptive. Historical pack names should appear as references/attribution, not as the primary brand unless permission is obtained.

## Tone

Nostalgic but not fake-retro. The project should feel like a serious preservation project that happens to be playable.

Avoid public-server visual language such as neon gradients, crate keys, rank badges, excessive holograms, or casino-style menus.

## Visual direction

The Archive should combine:

- Minecraft's blocky visual language
- museum/archive labels
- restrained industrial graphics
- collection-specific exhibit colors/textures
- simple iconography: machine gear, sword/tower, radiation/atom

The resource pack should use project-created assets unless third-party redistribution rights are documented.
