# Classic Tech: BuildCraft-style quarry vertical slice

## Goal
Implement a server-authoritative quarry that creates the classic automated-mining moment while remaining safe for a public persistent server.

## Acceptance criteria
- defined mining area.
- energy consumption.
- deterministic scan order.
- output inventory/transport integration.
- Polymer/virtual-entity presentation for moving head/frame as practical.
- chunk/restart safety.
- configurable limits and protection hooks.
- no duplication or unloaded-chunk corruption.
