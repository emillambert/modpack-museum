# Server modes

Each collection can expose more than one play style without forking the preservation implementation.

## PvE / Co-op

- persistent long-lived world
- grief protection where appropriate
- cooperative building and progression
- destructive technology constrained to avoid accidental server-wide loss
- no pay-to-win economy
- optional consensual PvP

## PvP / Seasonal

- team/faction-oriented world
- raiding and destructive systems enabled where they are part of the historical experience
- periodic resets/seasons so warfare does not permanently destroy years of history
- hard limits around server performance and malicious terrain destruction
- collection-specific rules rather than a generic factions plugin pasted over every mode

## Collection examples

**Classic Tech PvE:** factories, quarry networks, reactors, EMC progression and collaborative megabases.

**Classic Tech PvP:** hidden infrastructure, industrial progression race and constrained base raiding.

**Classic Adventure PvE:** exploration, bosses, structures and loot with friends.

**Classic Adventure PvP:** competing groups and scarce high-value adventure loot if testing shows it is fun.

**Classic Warfare PvE:** engineering playground for reactors, missiles and defenses with safe test areas.

**Classic Warfare PvP:** seasonal team warfare where missiles, radar, forcefields and strategic infrastructure are central.
